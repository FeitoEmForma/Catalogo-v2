# Feito em Forma — Catálogo v5.2 Premium
Atualização exclusivamente visual sobre a v5.1.
- Cabeçalho translúcido com efeito de vidro.
- Gradientes animados em verde, tipografia de destaque e espaçamento premium.
- Botões com movimento sutil e resposta ao toque.
- Cards com elevação e zoom suave nas fotos.
- Entrada gradual dos elementos durante a rolagem.
- Suporte a preferência por movimento reduzido.
- Mantidos scripts, painel ADM, banco, carrinho, produtos e WhatsApp.

## Publicação
1. Faça backup do repositório atual.
2. Extraia este ZIP.
3. Envie os arquivos da pasta para a raiz do repositório GitHub Pages.
4. Aguarde a publicação e atualize a página (Ctrl+F5).
5. Teste o catálogo, as fotos, o carrinho e o painel ADM.

Não é necessário executar novo SQL para esta atualização visual.
